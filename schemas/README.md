# Schemas

Shared, versioned API and data contracts between ArkNet components belong
here. No schema format, generation tooling, or contracts are introduced yet.
Contracts must preserve the privacy boundaries documented in the root README.

The Node release manifest (`arknet.node-release/v1`) is specified in
[docs/release-manifest.md](../docs/release-manifest.md); its authoritative
validator is `node-agent/internal/release`.
